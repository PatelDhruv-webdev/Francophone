# French Grammar Edge Cases — FrancoPath Reference

Every weird rule French throws at learners, organized so your app can teach them or flag them in exercise feedback. Use this as the source of truth when generating hints, error messages, and lesson content.

---

## 1. Articles & contractions

### The four definite articles

- `le` (m sing) — `le livre`
- `la` (f sing) — `la maison`
- `l'` (before vowel/silent h) — `l'ami`, `l'hôtel`
- `les` (plural, both genders) — `les livres`, `les maisons`

### Mandatory contractions

French **never** allows `de le`, `de les`, `à le`, or `à les`. They contract:

| Combination | Becomes | Example                  |
| ----------- | ------- | ------------------------ |
| `de + le`   | `du`    | `Je viens du Canada`     |
| `de + les`  | `des`   | `Le livre des enfants`   |
| `à + le`    | `au`    | `Je vais au cinéma`      |
| `à + les`   | `aux`   | `Je parle aux étudiants` |

`de + la`, `de + l'`, `à + la`, `à + l'` do **not** contract — they stay separate.

### Partitive articles (the "some" articles)

French marks uncountable quantities explicitly. English usually drops "some"; French doesn't.

- `du` (m) — `Je bois du café` (I drink coffee)
- `de la` (f) — `Je mange de la confiture` (I eat jam)
- `de l'` (before vowel) — `Je bois de l'eau`
- `des` (plural) — `Je mange des pommes`

**Critical rule:** in negative sentences, all partitive and indefinite articles become just `de` (or `d'` before vowel):

- `Je mange du pain` → `Je ne mange pas **de** pain`
- `J'ai un chien` → `Je n'ai pas **de** chien`
- `J'ai des amis` → `Je n'ai pas **d'**amis`

**Exception:** with `être`, the article does NOT change in negative: `Ce n'est pas **un** problème` (not `de problème`).

## 2. Gender — patterns and traps

There's no foolproof rule, but these patterns help (with their famous exceptions).

### Generally masculine endings

`-age` (le voyage), `-ment` (le moment), `-eau` (le bureau), `-isme` (le tourisme), `-eur` (le professeur — but feminine for emotions: la peur, la chaleur)

**Trap:** `la page`, `la plage`, `la cage`, `la nage`, `la rage` — feminine despite `-age`.

### Generally feminine endings

`-tion`/`-sion` (la nation, la décision), `-té` (la liberté), `-ée` (la journée — but le musée, le lycée), `-ence`/`-ance` (la science, la chance), `-ie` (la vie — but le génie), `-ette` (la baguette)

### Words that change meaning by gender

| Word     | Masculine                     | Feminine                |
| -------- | ----------------------------- | ----------------------- |
| livre    | le livre = book               | la livre = pound        |
| poste    | le poste = job/position       | la poste = post office  |
| tour     | le tour = turn/walk           | la tour = tower         |
| mode     | le mode = method              | la mode = fashion       |
| voile    | le voile = veil               | la voile = sail         |
| somme    | le somme = nap                | la somme = sum/amount   |
| manche   | le manche = handle            | la manche = sleeve      |
| critique | le critique = critic (person) | la critique = criticism |

### Words that keep one gender despite job

- `un médecin` — always masculine even for women: `Ma sœur est médecin`
- `un professeur` — traditionally invariable; modern Canadian/inclusive usage: `une professeure`
- `un mannequin` — always masculine, even for a female model
- `une personne` — always feminine, even for a man: `Cette personne est intelligente`
- `une victime` — always feminine
- `un bébé` — always masculine: `le bébé est joli` (even for a girl)

## 3. Adjective placement (BAGS rule)

Most adjectives go AFTER the noun: `une voiture rouge`, `un livre intéressant`.

**BAGS** = adjectives that go BEFORE the noun:

- **B**eauty: beau, joli
- **A**ge: jeune, vieux, nouveau, ancien
- **G**oodness: bon, mauvais, gentil
- **S**ize: grand, petit, gros, long, court, haut

Plus: `autre`, `même`, `tel`, `vrai`.

### Position changes meaning

Same adjective, different position = different meaning:

| Adjective | Before noun                 | After noun                        |
| --------- | --------------------------- | --------------------------------- |
| ancien    | un ancien collègue (former) | un meuble ancien (antique)        |
| cher      | un cher ami (dear)          | un livre cher (expensive)         |
| dernier   | la dernière fois (final)    | la semaine dernière (just past)   |
| grand     | un grand homme (great)      | un homme grand (tall)             |
| pauvre    | le pauvre garçon (pitiable) | un garçon pauvre (poor, no money) |
| propre    | ma propre voiture (own)     | une voiture propre (clean)        |
| seul      | une seule fois (only one)   | une femme seule (alone)           |

### Special masculine forms before vowels

`beau`, `nouveau`, `vieux`, `fou`, `mou` have a special form before a masculine noun starting with a vowel or silent h:

- `un bel homme` (not `un beau homme`)
- `un nouvel ami`
- `un vieil arbre`

Use the regular form before consonants: `un beau livre`, `un nouvel ordinateur` vs `un nouveau livre`.

## 4. Auxiliary selection — être vs avoir

90%+ of verbs use `avoir` in compound tenses. The exceptions matter.

### Verbs that ALWAYS take être

**The DR & MRS VANDERTRAMP / La Maison d'Être verbs** (intransitive verbs of motion/state change):

| Verb       | Pair                               |
| ---------- | ---------------------------------- |
| aller      | venir                              |
| arriver    | partir                             |
| entrer     | sortir                             |
| monter     | descendre                          |
| naître     | mourir                             |
| rester     | tomber                             |
| retourner  | passer (intransitive)              |
| devenir    | revenir                            |
| apparaître | (and all compounds of venir/tenir) |

Plus: all reflexive/pronominal verbs (se laver, se lever, etc.)

### Verbs that take BOTH (auxiliary changes meaning)

When transitive (with direct object) → `avoir`. When intransitive → `être`.

| Verb      | With avoir (transitive)                             | With être (intransitive)                     |
| --------- | --------------------------------------------------- | -------------------------------------------- |
| sortir    | J'ai sorti la poubelle (I took out the trash)       | Je suis sorti(e) hier (I went out yesterday) |
| monter    | J'ai monté les valises (I brought up the suitcases) | Je suis monté(e) en haut (I went up)         |
| descendre | J'ai descendu les escaliers                         | Je suis descendu(e) au sous-sol              |
| passer    | J'ai passé un examen                                | Je suis passé(e) chez toi                    |
| rentrer   | J'ai rentré la voiture                              | Je suis rentré(e) à 8h                       |
| retourner | J'ai retourné la crêpe                              | Je suis retourné(e) en France                |

## 5. Past participle agreement

The single biggest source of advanced errors. There are three rules.

### Rule A: With être (non-reflexive)

Past participle agrees with the **subject**:

- `Elle est allée` (f sing → +e)
- `Ils sont partis` (m pl → +s)
- `Elles sont nées` (f pl → +es)

### Rule B: With avoir

Past participle agrees with a **direct object that comes BEFORE the verb**.

If the direct object is after, no agreement:

- `J'ai mangé les pommes` — no agreement (object after)

If the direct object is before, agreement:

- `Les pommes que j'ai mangées` — feminine plural agreement
- `Je les ai mangées` — pronoun before, agreement
- `Quelle pomme as-tu mangée ?` — interrogative pronoun before, agreement

**Never agree with an indirect object:** `Je leur ai parlé` (no agreement — `leur` is indirect).

### Rule C: With reflexive verbs (être)

Past participle agrees with the reflexive pronoun **only if it functions as a direct object**:

- `Elle s'est lavée` — `se` is direct object (she washed herself) → agreement
- `Elle s'est lavé les mains` — `se` is indirect ("to herself"), `les mains` is direct (and follows) → no agreement
- `Les mains qu'elle s'est lavées` — `les mains` is direct AND comes before → agreement

## 6. Pronoun order (the cheat sheet)

When stacking object pronouns before a verb:

```
[me/te/se/nous/vous] → [le/la/les] → [lui/leur] → [y] → [en] → VERB
```

Examples:

- `Il me le donne` (he gives it to me)
- `Je le lui dis` (I tell it to him/her)
- `Nous y en avons trouvé` (we found some there)

### Affirmative imperative is different

With `tu`/`vous`/`nous` commands (positive only), pronouns go AFTER the verb with hyphens, AND `me`/`te` become `moi`/`toi`:

- `Donne-le-moi` (give it to me) — NOT `donne-moi-le`
- `Va-t'en` (go away) — note euphonic `t'` between vowels
- `Allons-y !` (let's go!)

In NEGATIVE imperative, normal order returns: `Ne me le donne pas`.

## 7. Negation — beyond ne...pas

The `ne...X` structure has many flavors:

| Negation        | Meaning                                    |
| --------------- | ------------------------------------------ |
| ne...pas        | not                                        |
| ne...jamais     | never                                      |
| ne...plus       | no longer / no more                        |
| ne...rien       | nothing                                    |
| ne...personne   | nobody                                     |
| ne...aucun(e)   | no / not any                               |
| ne...nulle part | nowhere                                    |
| ne...ni...ni    | neither...nor                              |
| ne...que        | only (not actually negative — restrictive) |

### Stacking

You can combine some: `Je ne dis plus jamais rien à personne` (I no longer ever say anything to anyone). The order matters: `plus` → `jamais` → `rien` → `personne`.

### Position with personne/aucun

`personne` and `aucun` go AFTER the past participle (unlike `pas`/`jamais`/`rien`/`plus`):

- `Je n'ai vu personne` (NOT `Je n'ai personne vu`)
- `Je n'ai aucune idée`

But `pas`, `jamais`, `rien`, `plus` go BETWEEN auxiliary and participle:

- `Je n'ai pas vu`, `Je n'ai jamais vu`, `Je n'ai rien vu`, `Je n'ai plus vu`

### Spoken French drops "ne"

In casual speech, `ne` is almost always dropped: `J'sais pas`, `J'ai rien fait`. **Teach this for listening comprehension** but the written/formal form keeps `ne`.

## 8. The subjunctive — when it's triggered

The subjunctive (`subjonctif`) is required after specific triggers, not free choice.

### Always triggers subjunctive

- **Wishes/wants:** `vouloir que`, `souhaiter que`, `aimer que`, `préférer que`
  - `Je veux que tu **viennes**`
- **Obligations:** `il faut que`, `il est nécessaire que`
  - `Il faut que tu **partes**`
- **Emotions:** `être content/triste/heureux que`, `avoir peur que`
  - `Je suis content qu'il **soit** là`
- **Doubt:** `douter que`, `ne pas penser que`, `ne pas croire que`
  - `Je doute qu'il **vienne**`
- **Certain conjunctions:** `bien que`, `quoique`, `pour que`, `afin que`, `avant que`, `jusqu'à ce que`, `à moins que`, `sans que`
  - `Je travaille pour que tu **réussisses**`

### Does NOT trigger subjunctive

- **Certainty:** `je pense que`, `je crois que`, `je sais que` (in affirmative — but negative/interrogative DOES trigger)
  - `Je pense qu'il **vient**` (indicative)
  - `Je ne pense pas qu'il **vienne**` (subjunctive)
- **Probability:** `il est probable que` (subjunctive: `il est peu probable que`)

### Same subject = use infinitive instead

If the subject is the same in both clauses, use infinitive, not subjunctive:

- `Je veux partir` (NOT `Je veux que je parte`)
- `Je veux que tu partes` (different subject → subjunctive)

## 9. Si clauses (conditional sentences)

Three patterns. Don't mix them up.

| Type                     | Si clause             | Result clause                 | Meaning                                                                             |
| ------------------------ | --------------------- | ----------------------------- | ----------------------------------------------------------------------------------- |
| Type 1 (real)            | si + present          | future / present / imperative | `Si tu viens, je serai content` (If you come, I'll be happy)                        |
| Type 2 (hypothetical)    | si + imparfait        | conditional present           | `Si j'avais de l'argent, j'achèterais une maison` (If I had money, I'd buy a house) |
| Type 3 (impossible past) | si + plus-que-parfait | conditional past              | `Si j'avais su, je serais venu` (If I had known, I'd have come)                     |

**Critical rule:** NEVER use future or conditional after `si` (when `si` means "if"). `Si je viendrai` is wrong.

## 10. Liaison — when to link words

Liaison = pronouncing a normally-silent final consonant when the next word starts with a vowel.

### Mandatory liaisons (always)

- After articles: `les_amis` /lez ami/, `un_ami` /œ̃n ami/
- After possessives: `mon_ami`, `ses_amis`
- After numbers: `deux_enfants`, `trois_heures`
- After short prepositions: `en_avion`, `sans_argent`
- After pronoun + verb: `nous_avons`, `ils_ont`, `vous_êtes`
- After adjective + noun (when adjective comes first): `un grand_homme`, `de bons_amis`

### Forbidden liaisons (never)

- After `et`: `un homme | et | une femme` (NEVER `et_un`)
- Before aspirated h: `les | héros`, `en | haut` (silent vs aspirated h must be memorized — dictionaries mark aspirated h with †)
- Before some numbers: `les | onze`, `le | huit`
- After singular noun before adjective: `un étudiant | américain` (don't liaison)

### Liaison consonant changes

- Final `s` and `x` pronounced as `/z/`: `les_amis` /lez ami/
- Final `d` pronounced as `/t/`: `un grand_homme` /œ̃ ɡʁɑ̃t ɔm/
- Final `f` pronounced as `/v/` only in `neuf heures` /nœv œʁ/ and `neuf ans`

## 11. Elision — when words shorten

Replace the final vowel of a one-syllable word with `'` before another vowel or silent h:

- `je` → `j'` : `j'ai`, `j'aime`
- `me` → `m'` : `il m'aime`
- `te` → `t'` : `il t'écoute`
- `se` → `s'` : `il s'appelle`
- `ne` → `n'` : `je n'ai pas`
- `de` → `d'` : `beaucoup d'amis`
- `le`/`la` → `l'` : `l'homme`, `l'eau`
- `que` → `qu'` : `qu'il vienne`
- `si` → `s'` : ONLY before `il`/`ils` — `s'il vient`. NEVER before `elle`: `si elle vient` (no elision)

**Exceptions — no elision:**

- Before aspirated h: `le héros` (no `l'héros`)
- Before names of letters/numbers used as nouns: `le un`, `la onze`
- `oui` doesn't trigger elision: `je crois que oui` (rare/optional `qu'oui`)

## 13. Tu vs vous (the register choice)

| Use `tu` with                       | Use `vous` with                                               |
| ----------------------------------- | ------------------------------------------------------------- |
| Family                              | Strangers, especially older                                   |
| Close friends                       | Boss, colleagues you don't know well                          |
| Children                            | Customers / clients                                           |
| Pets and animals                    | Anyone in a service relationship (waiter, doctor, shopkeeper) |
| Peers your age in informal settings | Anyone you'd address by title (Madame, Monsieur)              |
| Online communities (often)          | Job interviews always                                         |

### Rules of thumb

- **When in doubt, use `vous`.** It's never offensive; `tu` can be.
- The transition `tu` → `vous` requires permission: "On peut se tutoyer ?" (Can we use `tu`?)
- Quebec is somewhat more `tu`-tolerant than France; older France is stricter.
- French children use `tu` with parents but often `vous` with grandparents.

## 14. Common spelling/accent rules

### Cedilla (ç)

Add cedilla to `c` only before `a`, `o`, `u` to keep the soft `/s/` sound.

- `commencer` → `nous commençons` (cedilla added before `o`)
- `français` (cedilla before `a`)
- Never before `e` or `i`: `ce`, `ci` are already soft.

### Accents change meaning (homographs)

| Without accent        | With accent                    |
| --------------------- | ------------------------------ |
| a (verb avoir, "has") | à (preposition "to/at")        |
| ou (or)               | où (where)                     |
| la (the f)            | là (there)                     |
| sur (on)              | sûr (sure)                     |
| du (of the)           | dû (past participle of devoir) |
| jeune (young)         | jeûne (fasting)                |

### 1990 spelling reform — what changed

The 1990 reform made some traditional spellings optional. Both old and new are correct. Common changes:

- `oignon` → `ognon` (now optional)
- `nénuphar` → `nénufar`
- Removal of circumflex on `i` and `u` when not needed: `connaître` → `connaitre`, `coût` → `cout`, `île` → `ile`
- BUT circumflex stays where it distinguishes meaning: `dû` (must) vs `du` (of the); `mûr` (ripe) vs `mur` (wall); `sûr` (sure) vs `sur` (on)
- Hyphenation simplified in numbers: `vingt et un` → `vingt-et-un` (all numbers hyphenated)

**Recommendation for FrancoPath:** accept BOTH spellings as correct in user input; teach traditional spelling by default since it remains more common in publishing.

## 15. Quebec / Canadian French differences

Since you're in Ontario, this is a real differentiator. Differences worth teaching:

### Vocabulary

| Standard French    | Quebec French                                     |
| ------------------ | ------------------------------------------------- |
| voiture            | char (informal) / auto                            |
| téléphone portable | cellulaire                                        |
| email              | courriel (official term)                          |
| week-end           | fin de semaine                                    |
| petit-déjeuner     | déjeuner                                          |
| déjeuner (lunch)   | dîner                                             |
| dîner (dinner)     | souper                                            |
| pull               | chandail                                          |
| chaussures         | souliers                                          |
| baskets            | espadrilles                                       |
| shopping           | magasinage                                        |
| bonbon             | bonbon (same) but candy = "candy" loanword common |

### Pronunciation

- `t` and `d` become affricated `ts` and `dz` before `i`/`u`: "tu" sounds like "tsu"
- More diphthongs in vowels: "père" sounds more like "paèr"
- `oi` often pronounced `oé`: "moi" → "moé" (informal/older speakers)

### Grammar quirks

- More frequent use of `tu` after questions for emphasis: "Tu viens-tu ?"
- "À cause que" instead of "parce que" (informal)
- Some keep older subjunctive forms

### Numbers (matches Belgian/Swiss French)

- `septante` (70), `huitante`/`octante` (80), `nonante` (90) NOT used in Quebec — Quebec uses standard French (`soixante-dix`, etc.).

## 16. Quick error-flagging cheat sheet for your app

When the user makes one of these mistakes, you can pattern-match and give targeted feedback:

| Error pattern                                                | Likely issue               | Hint to show                                   |
| ------------------------------------------------------------ | -------------------------- | ---------------------------------------------- |
| `je suis 25 ans`                                             | "to be" age                | French uses `avoir`: `j'ai 25 ans`             |
| `je suis chaud/froid`                                        | physical state             | Use `avoir`: `j'ai chaud/froid`                |
| `je suis faim`                                               | hunger                     | `j'ai faim` (literal: "I have hunger")         |
| `je veux que je parte`                                       | same subject + subjunctive | Use infinitive: `je veux partir`               |
| `si je serai...`                                             | future after si            | After `si` use present: `si je suis`           |
| `je ne sais pas la réponse` (with avoir agreement attempted) | savoir vs connaître        | `savoir` for facts; for a person → `connaître` |
| `nous mangons`                                               | -ger spelling              | Add `e`: `nous mangeons`                       |
| `je payé`                                                    | participle alone           | Need auxiliary: `j'ai payé`                    |
| Missing accent on `où`, `à`, `là`                            | meaning conflict           | Show which homograph                           |

## 17. The 1990 reform and your app

Decision time: which spelling do you teach?

- **Default to traditional** (with circumflex, no hyphenated numbers) — still dominant in books, exams, France
- **Accept both** in user input validation
- **Mark Canadian/Quebec variants** as "Canadian" rather than wrong
- For the DELF/DALF (official French exams), traditional is what's tested
